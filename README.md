# NLP Movie Review

This repository contains a basic Natural Language Processing (NLP) pipeline for sentiment analysis on movie reviews using Naive Bayes classification.

## 📂 Files
- `main.py`: Entry point for running the pipeline.
- `movie_review.py`: Core logic for parsing and analyzing movie reviews.
- `text_analyse.py`: Text preprocessing and feature extraction.
- `nlp_test.py`: Test scripts for the classifier.
- `naivebayes.pickle`: Serialized model.
- `mr.txt`: Sample movie review input.
